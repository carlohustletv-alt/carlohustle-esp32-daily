# 02 Wi-Fi Scanner

Scan nearby Wi-Fi networks and show their names, signal strength, and security status in Serial Monitor.

## Parts

- ESP32 development board
- USB data cable

## Use

Upload `02_WiFi_Scanner.ino`, then open Serial Monitor at `115200` baud. Reset the board to scan again.

Only scan networks that you are authorized to test. This project does not connect to or attempt to access any network.
